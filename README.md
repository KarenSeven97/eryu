# 耳屿 · EAR LAB

个人音乐听觉训练实验室。中文界面，React + TypeScript + Vite PWA，优先适配触屏和桌面。无需账户、后端或付费 API。

## 启动

需要 Node.js 22.12+（建议 Node 24）。下载仓库后在根目录执行：

```powershell
npm ci
npm run dev
```

打开终端打印的地址。生产构建及预览：

```powershell
npm test
npm run build
npm run preview
```

`dist/` 可部署到任意 HTTPS 静态托管。Vite 使用相对路径，可部署在子目录。PWA 在生产构建中启用，开发服务器不注册离线缓存。

## 听觉训练

- 单音识别、音高比较、音程识别、多音听辨、和弦识别。
- 入门：自然音、常见音程、大小三和弦、2 音听辨。进阶：十二半音、13 种音程、7 种和弦、3–4 音听辨。
- 自由练习和每日课程（25 题，五类各 5 题，按本地日期恢复进度）。
- 随机题目、重听、判分、正确答案与琴键高亮，答题前隐藏题目音符。
- 钢琴、乐谱、题目以相同 MIDI 音高作为数据源。

## 长按记谱与编辑

在「自由钢琴」开启记谱，按下琴键并松手，即可留下音符。

- 按住时长按当前 BPM 量化：少于 1.5 拍为四分、1.5–3 拍为二分、3 拍及以上为全音符。例如 90 BPM 时，阈值为 1 秒与 2 秒；按住约 1.3 秒得到二分，约 2.7 秒得到全音符。
- 开始时间相差小于 90ms 的琴键合为和弦，取较长时值。
- 点击下方音符卡片可修改四分/二分/全音符，或删除该组音符；也可撤销末尾。
- 点击「播放整段」按谱面顺序和当前速度连续回放，播放时高亮音符和琴键，可随时停止。
- 自动保存当前作品（最多 128 组）及 BPM 到 IndexedDB，刷新或重新进入可恢复。
- 记谱忽略按键间空白，按顺序紧密排列；不是自由节奏的录音器。目前不提供独立休止符输入、节拍小节校验、跨声部独立时值、MIDI/MusicXML 导出或多作品管理。

## 钢琴与乐谱

两八度 25 键（C3–C5 / C4–C6），触屏多指、鼠标以及聚焦琴键后空格/回车发声；失焦、触控取消不留下意外音符。小屏可在琴键区域横向滚动。

Tone.js Sampler 使用本地 Salamander Grand Piano MP3 子集，13 个采样覆盖 C3–C6，间隔音高由采样器移调。作者 Alexander Holm，CC BY 3.0；来源、署名和许可证见 `public/samples/salamander/ATTRIBUTION.md`。这是单层轻量音色，并非原始 16 力度层完整琴库。

VexFlow 显示高低音谱号、升降号、四分/二分/全音符和和弦。创作谱的另一谱表会显示对应占位休止符；每行最多 4 组音符，不宣称每行为一个完整小节。升降号偏好影响琴键及谱面，训练答案采用升号等音名。

## 五维能力图

训练记录显示五边形网状雷达图，五类训练起点均为 0。每类能力值：

`100 × 加权答对数 / 题数 × min(题数 / 20, 1)`

进阶正确题权重 1，入门正确题 0.6，错误题 0。20 题全对入门为 60，进阶为 100；旧版未保存难度的记录按入门计算。这是可解释的练习指标，不是专业能力评级。旁边保留实际题量和正确率。

## PWA 与隐私

首次联网完整打开生产版本后，应用、字体、钢琴采样和许可文件均预缓存，可离线重开。第一次发声必须点击播放或琴键解锁音频。

- iPhone/iPad：Safari 分享 → 添加到主屏幕。
- Windows：Edge/Chrome 地址栏安装入口。
- 安装及 Service Worker 需 HTTPS；localhost/127.0.0.1 是本机例外。
- 无云端训练数据。清理网站数据、隐私模式退出或系统存储回收可能删除记录和作品。
- 训练统计可导出 JSON；作品当前只保存在本机，尚未加入备份导入和跨设备同步。
- 更新后若仍看到旧版，请等待缓存更新后再次刷新。

## 项目结构

- `src/music.ts`：Tonal、MIDI、题库和判分。
- `src/audio.ts`：采样加载、琴键发声、题目及作品回放。
- `src/Piano.tsx`：多点触控与长按事件。
- `src/Composer.tsx`、`composition.ts`、`Score.tsx`：作品、时值、编辑和谱面。
- `src/Radar.tsx`、`abilities.ts`：能力值及五维图。
- `src/storage.ts`：IndexedDB；保留原 `ear-lab` 数据库名以兼容旧记录。
- `src/*.test.ts`：题库、作品时值、能力评分和存储测试。
- `public/`：图标、采样及第三方许可。

## 验证与后续
